# Control-plane · портал (Control Plane)

Единая точка входа в стенд из 30+ сервисов: **живой статус здоровья** каждого
сервиса, **агрегация по категориям** и **ссылки на все дашборды**. Опрашивает
`/api/health` каждого компонента и показывает, кто онлайн, на каком движке
(детерминированный/Claude) и с какой задержкой.

```
портал ──/api/health──▶ [ роутеры · уровни · ИИ-коммерция · ИИ-операции · качество ]
        ◀── up/down + движок + латентность ──  сетка карточек со ссылками на дашборды
```

## Что показывает

- **Статус** каждого сервиса (online/offline) с индикатором и задержкой health-опроса.
- **Движок** (`rules` — детерминированный, `llm` — активен Claude по ключу).
- **Категории**: Маршрутизация · Уровни · ИИ · коммерция · ИИ · операции · Качество —
  с долей «онлайн» по каждой.
- **Ссылки** на дашборд каждого сервиса — портал как навигация по всему стенду.

Реестр сервисов настраивается через `PORTAL_SERVICES` (JSON); по умолчанию — полный
набор стенда с внутренними адресами compose.

## Запуск

```bash
npm install
# по умолчанию — реестр всего стенда (адреса по именам сервисов compose)
export POLL_MS=10000   # авто-опрос (0 — по запросу)
npm start              # → http://localhost:8099
```

Портал: сетка карточек по категориям, автообновление, клик по карточке ведёт на
дашборд сервиса.

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET`  | `/api/health` | статус портала |
| `GET`  | `/api/services` | реестр сервисов + ссылки на дашборды |
| `GET`  | `/api/status` | живой опрос: up/down/движок/латентность + агрегаты по категориям |
| `POST` | `/api/ask` | сводка по стенду (кто упал, по категориям, LLM) |

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `PORTAL_SERVICES` | полный реестр стенда | Список сервисов (JSON) |
| `PORTAL_TIMEOUT_MS` | `2000` | Таймаут health-опроса |
| `POLL_MS` | `0` | Период автообновления (0 — по запросу) |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | — / `claude-opus-4-8` | LLM-сводка |
| `PORT` | `8099` | Порт |

## Тест

```bash
npm test
```

`test/smoke.mjs` поднимает три сервиса (up/rules, up/llm, offline) и проверяет:
опрос статусов (2 онлайн / 1 offline), распознавание движка, агрегацию по
категориям, и HTTP (`/api/services` со ссылками, `/api/status`, `/api/ask`
перечисляет упавшие). Без сети и ключа. 9/9.

## Файлы

| Файл | Роль |
|------|------|
| `registry.js` | Реестр сервисов стенда (id/имя/категория/url/дашборд) |
| `monitor.js` | Опрос `/api/health` + агрегация по категориям |
| `store.js` / `interpret.js` | Снимок статусов и детерминированная сводка |
| `server.js` | Express: `/api/status`, `/api/services` |
| `public/index.html` | Портал: сетка карточек со статусом и ссылками |
| `test/smoke.mjs` | Смоук-тест опроса и агрегации |
