# Автономный управляющий (Autonomous Manager)

ИИ-управляющий, который **не только советует, но и действует** — замкнутая петля
**наблюдение → анализ → действие** через единый контракт. Ключ к безопасности —
**порог эскалации человеку**: безопасные действия петля выполняет сама, рискованные
кладёт в очередь на одобрение. Плюс жёсткие предохранители: сухой прогон, лимит
действий за цикл, cooldown по товару, kill-switch и полный аудит.

```
┌─ наблюдение (/api/products) → анализ (спрос/дозаказ/цена/аномалии) → предложения
│         │
│         ▼  шлюз по impact
│   impact ≤ порога → АВТО-исполнение ──┐
│   impact >  порога → очередь человеку │→ эффектор → ledger + аудит
│                       approve/reject ─┘        │
└──────────────────── следующий цикл ◀───────────┘
```

## Порог автономии (эскалация человеку)

Каждое предложенное действие получает **impact (0..100)**; политика решает судьбу:

| Тип действия | impact | По умолчанию |
|--------------|--------|--------------|
| **Дозаказ** | по стоимости закупки vs бюджет | дешёвый → **авто**, дорогой → **к человеку** |
| **Смена цены** | 40 + \|Δ%\|·2 (клиентское, чувствительное) | почти всегда **к человеку** |
| **Пометка аномалии** | 5 (информационное) | **авто** |

`impact ≤ autoThreshold` → петля исполняет сама; иначе → **очередь одобрения**
(`/api/approve/:id` · `/api/reject/:id`). Так рутина автоматизируется, а решения с
последствиями всегда остаются за человеком.

## Предохранители

- **Сухой прогон** (по умолчанию **включён**) — действия только симулируются, без реального эффекта.
- **Лимит действий за цикл** — защита от лавины.
- **Cooldown по товару** — не трогать один товар N циклов подряд.
- **Kill-switch** (`/api/pause`) — мгновенная остановка всей автономии.
- **Аудит** — каждое событие (предложено/авто/в очередь/одобрено/отклонено/пропущено) в журнале.

## Эффекторы

Единый контракт намеренно read-mostly (нет ops-записи), поэтому исполнитель по
умолчанию — безопасный **ledger** (фиксирует и описывает эффект). В реальном
развёртывании `EFFECTOR_URL` направляет действия на настоящую систему (поставщик,
админ-API уровня) через вебхук.

## Два движка объяснения, одно ядро

`POST /api/ask`: с `ANTHROPIC_API_KEY` — Claude-советник (факты только из инструмента
`loop_state`, рекомендует одобрить/отклонить); без ключа — детерминированные ответы
(очередь, журнал, аудит, режим). Ядро принятия решений всегда детерминировано.

## Запуск

```bash
npm install
export BACKEND_URL=http://localhost:8080   # роутер или любой уровень
export AUTO_DRY_RUN=true                     # сухой прогон (снять для реального исполнения)
export LOOP_MS=0                             # >0 — автопетля каждые N мс
# export ANTHROPIC_API_KEY=sk-ant-...
npm start                                    # → http://localhost:8077
```

Дашборд: индикаторы режима/предохранителей, кнопки «прогнать цикл», «сухой
прогон», «пауза», очередь одобрений с кнопками одобрить/отклонить, журнал действий,
чат с советником.

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET`  | `/api/health` / `/api/state` | статус и режим петли |
| `GET` / `POST` | `/api/config` | политика (dryRun, autoThreshold, лимиты) |
| `POST` | `/api/snapshot` | наблюдение: снять каталог в ряд |
| `POST` | `/api/cycle` | один цикл управления (`{observe:true}` — со снимком) |
| `GET`  | `/api/pending` | очередь на одобрение |
| `POST` | `/api/approve/:id` · `/api/reject/:id` | решение человека |
| `POST` | `/api/pause` · `/api/resume` | kill-switch |
| `GET`  | `/api/ledger` · `/api/audit` | журнал действий и аудит |
| `POST` | `/api/ask` | объяснение состояния петли |

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `BACKEND_URL` | `http://localhost:8080` | Бэкенд единого контракта |
| `AUTO_DRY_RUN` | `true` | Сухой прогон (без реальных эффектов) |
| `AUTO_THRESHOLD` | `30` | Порог impact для авто-исполнения |
| `MAX_ACTIONS` / `COOLDOWN` | `5` / `3` | Лимит за цикл / cooldown по товару |
| `REORDER_BUDGET` | `200` | Масштаб «дорогого» дозаказа (€) |
| `EFFECTOR_URL` | — | Вебхук реального исполнителя |
| `LOOP_MS` | `0` | Период автопетли (0 — выкл) |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | — / `claude-opus-4-8` | LLM-советник |
| `PORT` | `8077` | Порт |

## Тест

```bash
npm test
```

`test/smoke.mjs` проверяет все предохранители: шлюз (дешёвый дозаказ → авто; дорогой
и смена цены → эскалация), одобрение/отклонение, cooldown, сухой прогон vs реальное
исполнение, kill-switch, лимит действий за цикл и HTTP-путь целиком. Без сети и
ключа. 21/21.
