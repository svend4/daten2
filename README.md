# Distillation-as-deployment 🎓🚀🌷

MLOps-конвейер, превращающий **обученную модель-ученика в версионируемый сервис**: канареечный гейт качества, продакшн-инференс и **авто-откат** при просадке согласия с учителем ниже SLO. Замыкает петлю после дистилляции: `:8089` *обучает* крошечную модель — здесь она безопасно *живёт в проде*.

> Часть системы [flower-shop / 7 уровней](https://github.com/svend4/daten2). Модель-ученик классифицирует намерение реплики покупателя (каталог/цена/заказ/приветствие/прочее), имитируя учителя-правила; согласие с учителем — метрика качества.

## Чем отличается от соседей по системе

| Сервис | Роль |
|---|---|
| **Дистилляция** `:8089` | **обучает** ученика из разметки учителя |
| **shadow/canary** `:8094` | зеркалит **HTTP-трафик** между версиями бэкенда |
| **авто-эвалы** `:8090` | эвалы **ответов ИИ** против rubric |
| **Distill-deploy** | **жизненный цикл модели**: версия → канареечный гейт → прод-инференс → авто-откат |

## Как это работает

1. **Артефакт модели** (`model.js`) — крошечная softmax-регрессия над хэш-мешком токенов; детерминированное обучение (init нулями) → воспроизводимый `serialize`-артефакт весов, который и есть выкатываемая версия.
2. **Реестр версий** (`registry.js`) — жизненный цикл `canary → production → retired / rolled-back`; продакшн-указатель + стек прежних продакшн-версий для отката.
3. **Канареечный гейт** (`pipeline.deploy`) — новая версия оценивается на eval-выборке; промоушен только если **согласие ≥ SLO** (`SLO_FLOOR`, по умолчанию 0.8) **и не хуже действующей** (с допуском). Иначе — отказ, продакшн не трогается.
4. **Продакшн-инференс** — `/api/predict` отдаёт предсказание текущей продакшн-модели.
5. **Авто-откат** (`pipeline.monitor`) — живое согласие продакшн-модели на свежих данных; ниже SLO → **атомарный откат** указателя к последней хорошей версии + запись инцидента. Ловит канареечные слепые пятна (версия прошла узкий канареечный набор, но провалилась на реальном трафике).
6. **Два движка**: без ключа — детерминированный конвейер. С `ANTHROPIC_API_KEY` — **LLM-диагност** (`claude-opus-4-8`): concept-drift / canary-blindspot / undertrained + действие.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET  | `/api/health` | движок, SLO, статистика реестра |
| POST | `/api/deploy` | `{version?, epochs?, trainSeed?, classes?, evalClasses?, artifact?}` → обучить+гейт |
| GET  | `/api/models` | версии, продакшн, инциденты |
| GET  | `/api/production` | текущая продакшн-версия (артефакт) |
| POST | `/api/predict` | `{text}` → предсказание продакшн-модели + метка учителя |
| POST | `/api/monitor` | `{samples?/classes?}` → живое согласие + возможный авто-откат |
| POST | `/api/ask` | объяснение словами (продакшн, откаты) |

## Запуск

```bash
npm install
npm test                 # 16 проверок: гейт, промоушен, слепой канареечный набор → авто-откат, инференс, HTTP
node server.js           # :8109, дашборд на /
```

Дашборд (`/`): кнопки выката (хорошая / недоученная / со слепым пятном), проверка дрейфа order-heavy, инференс, таблица версий со статусами и канареечным согласием, журнал с инцидентами.

## Переменные окружения

| Переменная | Смысл |
|---|---|
| `PORT` | порт (по умолчанию 8109) |
| `SLO_FLOOR` | минимальное согласие с учителем для промоушена/удержания (0.8) |
| `ANTHROPIC_API_KEY` | включает LLM-диагност регрессии |

Смоук-тест проходит весь цикл детерминированно: v1 (полное обучение) промоучена; недоученная v2 (0 эпох) отклонена гейтом; v3 обучена БЕЗ класса «order» и проходит слепой канареечный набор (тоже без order) — но на живом order-heavy трафике проседает ниже SLO, и срабатывает авто-откат к v1, которая этот трафик держит.
