# Vision · поиск по фото (Vision)

Компьютерное зрение для магазина: **анализ изображений**, **поиск букета по фото** и
**авто-теги/описания** товаров. Каталог берётся через **единый контракт**. Ядро
детерминированное (собственный PNG-кодек + цветовой анализ, без зависимостей); с
`ANTHROPIC_API_KEY` подключается **Claude-vision** для богатого распознавания любого
формата.

```
фото → [цветовое ядро: PNG-декод → доминирующий цвет → тип цветка]  ┐
       [Claude-vision: тип/цвет/теги/описание — любой формат]        ┼→ теги + описание
                                                                     └→ поиск по каталогу (× контракт)
```

## Детерминированное «зрение» (без ключа)

- **Свой PNG-кодек** на встроенном `zlib` (декод 8-бит RGB/RGBA, фильтры 0–4;
  и кодирование сплошного цвета для демо) — настоящая работа с пикселями, без библиотек.
- **Цветовой анализ**: сэмплирование пикселей → средний цвет → классификация
  (красный/жёлтый/розовый/белый/зелёный) → **тип цветка + смысловые оси + теги**
  (красный → розы/романтика, жёлтый → тюльпаны/яркость, розовый → пионы/нежность).
- **Поиск по фото**: тип цветка сопоставляется с каталогом → ранжированные товары.

## Claude-vision (с ключом)

Мультимодальный анализ понимает **JPEG/PNG/WebP/GIF**: возвращает вид цветка, цвет,
теги, повод и **продающее описание** для карточки (structured output). Идеально для
авто-заполнения каталога из фотографий.

## Запуск

```bash
npm install
export BACKEND_URL=http://localhost:8080   # роутер или любой уровень
# export ANTHROPIC_API_KEY=sk-ant-...        # включить Claude-vision
npm start                                    # → http://localhost:8088
```

Дашборд: перетащите фото (или сгенерируйте демо-цвет в браузере) → анализ (цвет,
теги, описание) + похожие товары из каталога.

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET`  | `/api/health` | `{ ok, engine, backend }` |
| `POST` | `/api/analyze` | `{ imageBase64, mediaType }` → цвет/тип/теги/описание (+ Claude при ключе) |
| `POST` | `/api/search-by-photo` | фото → ранжированные товары каталога |
| `POST` | `/api/autotag` | фото → теги + описание для карточки товара |

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `BACKEND_URL` | `http://localhost:8080` | Бэкенд единого контракта |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | — / `claude-opus-4-8` | Claude-vision |
| `PORT` | `8088` | Порт |

## Тест

```bash
npm test
```

`test/smoke.mjs` проверяет: PNG-кодек (round-trip, отказ на не-PNG), классификацию
цвета → тип цветка (красный→роза, жёлтый→тюльпан, розовый→пион), поиск по фото
(сопоставление каталога), и HTTP (`/api/analyze`, `/api/search-by-photo`,
`/api/autotag`, битый вход → 400). Изображения синтезируются на лету. Без сети и
ключа. 13/13.

## Файлы

| Файл | Роль |
|------|------|
| `png.js` | Минимальный PNG-кодек (декод + кодирование сплошного цвета, CRC32) |
| `vision.js` | Цветовой анализ → тип цветка/оси/теги + сопоставление каталога |
| `vision-llm.js` | Claude-vision (мультимодальный, structured output) |
| `contract.js` | Клиент контракта (каталог) |
| `server.js` | Express: `/api/analyze`, `/api/search-by-photo`, `/api/autotag` |
| `public/index.html` | Дашборд: загрузка фото, анализ, похожие товары |
| `test/smoke.mjs` | Смоук-тест кодека, классификации и HTTP |
