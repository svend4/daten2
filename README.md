# RAG + память (RAG & Memory)

Консультант магазина, который **отвечает по базе знаний** (уход за цветами, поводы,
доставка, оплата, возврат) и **помнит клиента** (любимые товары, поводы, бюджет) —
для персонализации и рекомендаций. Каталог берётся через **единый контракт**.

```
вопрос → извлечение из базы знаний (top-k) ┐
          пер-клиентская память (prefs/history) ┼→ grounded-ответ + источники
                                                └→ персонализированные рекомендации (каталог × память)
```

## RAG (извлечение → grounded-ответ)

База знаний — документы-чанки с тегами (`care-rose`, `delivery`, `returns`, …).
Извлечение **детерминированное** (без внешних эмбеддингов): скор по совпадению
токенов запроса с тегами (вес 2) и текстом (вес 1), возвращаются top-k.

- **Без ключа** — ответ строится из верхнего чанка + персонализация из памяти.
- **С `ANTHROPIC_API_KEY`** — Claude отвечает **строго по извлечённому контексту**
  и памяти (grounded, не выдумывает; если ответа нет в базе — так и говорит).

Каждый ответ приводит **источники** (какие разделы базы использованы).

## Память клиента

Пер-клиентское хранилище (в памяти + опц. `data/memory.json`):
`preferences.favorites / occasions / budget` и `history` (последние вопросы/события).
Память **влияет и на ответы, и на рекомендации** — это temporal-ярус канонической
схемы (`carts`, `view_stats`), доведённый до персонализации.

## Персонализированные рекомендации

`POST /api/recommend` скорит каталог: **любимое** (+1.0), **под повод** (+0.6,
через карту повод→тип цветка), **в бюджете** (+0.3), featured (+0.5) — и возвращает
top-5 с причинами. Без памяти — разумный дефолт по featured.

## Запуск

```bash
npm install
export BACKEND_URL=http://localhost:8080   # роутер или любой уровень
# export ANTHROPIC_API_KEY=sk-ant-...        # grounded-ответы Claude
npm start                                    # → http://localhost:8079
```

Дашборд: панель клиента (запомнить любимое/повод/бюджет), рекомендации, чат-консультант
с показом источников под каждым ответом.

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET`  | `/api/health` / `/api/kb` | статус и список документов базы |
| `POST` | `/api/ask` | `{ customerId, question }` → `{ answer, sources, usedMemory }` |
| `GET`/`POST`/`DELETE` | `/api/memory/:id` | чтение/обновление/сброс памяти клиента |
| `POST` | `/api/recommend` | `{ customerId }` → персонализированные рекомендации |

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `BACKEND_URL` | `http://localhost:8080` | Бэкенд единого контракта |
| `DATA_DIR` | `./data` | Персистентность памяти |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | — / `claude-opus-4-8` | Grounded-ответы Claude |
| `PORT` | `8079` | Порт |

## Тест

```bash
npm test
```

`test/smoke.mjs` проверяет: извлечение релевантных чанков (уход/доставка/возврат;
нерелевантный запрос → пусто), grounded-ответ с источниками и честный отказ вне базы,
сохранение памяти и её влияние на ответ, запись истории, и персонализированные
рекомендации (любимое вверху, повод отмечен, дефолт без памяти). Без сети и ключа. 16/16.
