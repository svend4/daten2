# ИИ-управляющий магазином цветов (AI manager / agent)

Автономный управляющий, который **следит за магазином через тот же единый
контракт**, что и витрина: периодически снимает каталог (`/api/products`),
строит временной ряд и выводит операционные решения — прогноз спроса, точку и
объём дозаказа, подсказки по ценам, аномалии. Работает поверх **любого из семи
уровней** или роутера.

```
любой уровень (L1…L7) / роутер ─/api/products→ снимки ─→ аналитика ─→ решения
```

## Ключевая идея: спрос из просадки остатков

Единый контракт намеренно **не** отдаёт список заказов (заказы ищутся по
непубличному токену). Поэтому управляющий выводит спрос иначе — из **падения
остатков между снимками**: `продажи = остаток(t₁) − остаток(t₂)`. Этого
достаточно для скорости продаж, прогноза исчерпания, дозаказов и аномалий —
без привилегированного доступа к заказам. Дозавоз (рост остатка) распознаётся и
не считается продажей.

## Что считает ядро (детерминированно)

| Метрика | Как |
|---------|-----|
| **Спрос** `dailyRate` | средняя просадка остатка на сутки |
| **Прогноз** `daysToStockout` | `остаток / спрос` |
| **Дозаказ** | точка заказа `спрос×(срок+страховка)`; объём — до покрытия на `COVERAGE_DAYS` |
| **Цена** | закончится раньше поставки → поднять; не продаётся при остатке → скидка; иначе держать |
| **Аномалии** | z-оценка последнего интервала спроса (всплеск/провал), смена цены, дозавоз |

## Два движка вопросов, одно ядро

`POST /api/ask` отвечает на вопросы владельца:

| Движок | Когда | Что делает |
|--------|-------|------------|
| **`llm`** (Claude API) | задан `ANTHROPIC_API_KEY` | Claude отвечает на естественном языке, беря числа **только** из инструментов `get_report` / `get_products` (модель `claude-opus-4-8`) |
| **`rules`** | ключа нет | Детерминированные ответы по отчёту (дозаказ / аномалии / цены / прогноз) |

Так дашборд работает и демонстрируется **без ключа**, а с ключом становится
диалоговым советником.

## Запуск

```bash
npm install
export BACKEND_URL=http://localhost:8080   # любой уровень или роутер
export POLL_MS=3600000                      # автоснимок раз в час (0 = выкл)
# export ANTHROPIC_API_KEY=sk-ant-...        # включить LLM-советник
npm start                                    # → http://localhost:8071
```

Дашборд: кнопка «Снимок каталога» добавляет точку в ряд; таблица показывает
спрос, прогноз, дозаказ, цену и аномалии; чат внизу — вопросы управляющему.

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET`  | `/api/health`   | `{ ok, engine, backend, snapshots }` |
| `POST` | `/api/snapshot` | снять текущий каталог в ряд |
| `GET`  | `/api/report`   | полный аналитический отчёт |
| `POST` | `/api/ask`      | `{ sessionId, message }` → `{ reply, engine }` |

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `BACKEND_URL` | `http://localhost:8080` | Бэкенд единого контракта |
| `POLL_MS` | `0` | Период автоснимка (мс); 0 — выключено |
| `LEAD_TIME_DAYS` / `SAFETY_DAYS` / `COVERAGE_DAYS` | `3` / `2` / `14` | Параметры дозаказа |
| `ANOMALY_Z` / `MIN_SAMPLES` | `2.5` / `4` | Порог и минимум выборки для аномалий |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | — / `claude-opus-4-8` | LLM-советник |
| `DATA_DIR` | `./data` | Персистентность ряда снимков |
| `PORT` | `8071` | Порт |

## Тест

```bash
npm test
```

`test/smoke.mjs` (1) снимает каталог через mock-бэкенд контракта, (2) прогоняет
синтетический ряд из 10 суточных снимков и проверяет спрос, прогноз, дозаказ,
подсказки по цене и аномалии (всплеск, смена цены), (3) проверяет `/api/report`
и `/api/ask` на детерминированном движке. Без сети и API-ключа. 19/19.
