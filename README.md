# Разговорная витрина магазина цветов (AI storefront)

ИИ-консультант, который **продаёт покупателю через диалог**: понимает запрос на
естественном языке, показывает каталог, собирает корзину и оформляет заказ —
обращаясь к магазину **только через единый контракт** (`/api/products`,
`/api/orders`). Поэтому витрина работает поверх **любого из семи уровней** или
поверх capability-роутера — бэкенд взаимозаменяем.

```
покупатель ⇄ разговорная витрина ⇄ единый контракт ⇄ любой уровень (L1…L7) / роутер
```

## Два движка, один интерфейс

| Движок | Когда активен | Что делает |
|--------|---------------|------------|
| **`llm`** (Claude API) | задан `ANTHROPIC_API_KEY` | Claude ведёт диалог и вызывает инструменты `list_products` / `create_order` / `get_order` в цикле tool-use; цены и заказы — только с сервера |
| **`rules`** (детерминированный) | ключа нет | Разбор намерений на правилах (RU): каталог, фильтр по цене/рекомендуемым, добавление в корзину, оформление |

Оба движка отвечают на один и тот же `POST /api/chat`, поэтому витрину можно
демонстрировать и тестировать **без API-ключа**, а с ключом она становится
полноценным LLM-продавцом. Модель по умолчанию — `claude-opus-4-8`
(переопределяется `ANTHROPIC_MODEL`).

## Запуск

```bash
npm install

# бэкенд — любой уровень или роутер, отдающий единый контракт:
export BACKEND_URL=http://localhost:8080

# необязательно — включить LLM-движок:
export ANTHROPIC_API_KEY=sk-ant-...
# export ANTHROPIC_MODEL=claude-opus-4-8

npm start           # → http://localhost:8070
```

Откройте `http://localhost:8070` — чат с быстрыми подсказками
(«Каталог», «Рекомендуемые до 2 €», «+2 розы», «Оформить»).

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET`  | `/api/health` | `{ ok, engine, backend }` — какой движок активен и куда ходит |
| `POST` | `/api/chat`   | `{ sessionId, message }` → `{ reply, engine, cart }` |

Сессии диалога хранятся в памяти по `sessionId`.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `BACKEND_URL` | `http://localhost:8080` | Бэкенд единого контракта |
| `ANTHROPIC_API_KEY` | — | Включает LLM-движок |
| `ANTHROPIC_MODEL` | `claude-opus-4-8` | Модель Claude |
| `PORT` | `8070` | Порт витрины |

## Тест

```bash
npm test
```

`test/smoke.mjs` поднимает mock-бэкенд единого контракта, запускает витрину на
детерминированном движке (без ключа) и проигрывает полный сценарий покупки:
каталог → фильтр по цене → добавление товаров → корзина → оформление →
проверка, что заказ дошёл до бэкенда. Не требует сети и API-ключа.

## Файлы

| Файл | Роль |
|------|------|
| `server.js` | Express: выбор движка, `/api/chat`, `/api/health`, статика |
| `llm.js` | LLM-движок — цикл tool-use Claude API поверх контракта |
| `nlu.js` | Детерминированный движок — разбор намерений на правилах |
| `shop.js` | Клиент единого контракта + клиентские фильтры |
| `public/index.html` | Чат-интерфейс |
| `test/smoke.mjs` | Смоук-тест детерминированного пути |
