# flower-shop-mcp-server — ИИ-переходник к магазину

MCP-сервер, дающий ИИ (Claude и любому MCP-клиенту) инструменты для управления
магазином цветов. Работает с **любым из 7 уровней** или с капабилити-роутером —
потому что все они реализуют **единый контракт** (`openapi.yaml`).

## Инструменты
| Инструмент | Действие | Тип |
|-----------|----------|-----|
| `flowershop_health` | какой уровень отвечает, жив ли магазин | read-only |
| `flowershop_list_products` | каталог с фильтрами (search / featured / max_price / in_stock) | read-only |
| `flowershop_create_order` | оформить заказ (цены с сервера, возвращает токен) | запись |
| `flowershop_get_order` | заказ по непубличному номеру | read-only |

## Запуск
```bash
npm install
npm run build
# BACKEND_URL — адрес любого уровня или роутера (по умолчанию http://localhost:8080)
BACKEND_URL=https://<любой-уровень>.onrender.com npm start
```

## Подключение к ИИ-клиенту (пример конфигурации)
```json
{
  "mcpServers": {
    "flower-shop": {
      "command": "node",
      "args": ["/путь/к/dist/index.js"],
      "env": { "BACKEND_URL": "https://<уровень-или-роутер>" }
    }
  }
}
```
После этого ИИ может: «покажи рекомендованные товары до 2 €», «оформи заказ на
2 красные розы для Ивана», «проверь статус заказа <токен>». Один адаптер — все 7 магазинов.

## Тест
```bash
npm test   # мок-бэкенд по контракту + реальный stdio-хендшейк + вызовы всех инструментов
```

## Почему это работает
Единая схема данных → единый API-контракт → этот MCP-адаптер. ИИ получает
стабильный интерфейс инструментов и управляет любой реализацией магазина
без привязки к её стеку (PHP / Flask / Django / Node / Next.js / микросервисы).
