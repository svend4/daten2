# Авто-эвалы и LLM-as-judge (Evals)

Непрерывный контроль качества: харнесс прогоняет **эвал-кейсы** против цели —
проверяет **соответствие контракту**, **инварианты** и **качество поведения** витрины,
строит **scorecard** и ловит **регрессии** против baseline. Так поведение ИИ и уровней
контролируется машинно, а не «на глаз».

```
цель (уровень/роутер/витрина) ──▶ [эвал-кейсы] ──▶ scorecard (балл 0–100, pass/fail)
                                                     └─ сравнение с baseline → регрессии
```

## Два набора кейсов

**Контрактный** (против бэкенда контракта) — детерминированные проверки:

| Кейс | Что проверяет |
|------|---------------|
| `products-shape` | `/api/products` — массив, поля и типы (`id`,`name`,`price`) |
| `order-create` | `POST /api/orders` → `order_number` + `total` |
| `order-total-invariant` | **инвариант** `total = Σ цена×кол-во` |
| `order-lookup` | поиск заказа по токену |
| `order-privacy` | **безопасность**: чужой/неверный токен → 404, не IDOR |
| `order-validation` | пустой заказ → 4xx |

**Поведенческий** (против витрины `/api/chat`) — сценарные диалоги: показывает
каталог, добавляет в корзину, доводит до оформления.

## Scorecard, baseline и регрессии

Каждый прогон даёт **взвешенный балл 0–100** и результат по кейсам. Сохраните прогон
как **baseline** — и последующие прогоны показывают **регрессии** (что проходило, но
упало) и **исправления**, с Δбалла. Это ловит деградацию поведения ИИ/уровней между
версиями.

## LLM-as-judge (с ключом)

`POST /api/judge` — Claude оценивает произвольный ответ по рубрике (helpfulness,
correctness, **grounding**, **safety**) баллами 0–5 и выносит вердикт pass/warn/fail.
Для открытых, не бинарных проверок качества диалога. Без ключа работает
детерминированный набор.

## Запуск

```bash
npm install
export TARGET_URL=http://localhost:8080   # цель контрактных эвалов (роутер/уровень)
export CHAT_URL=http://localhost:8070      # витрина для поведенческих эвалов
# export ANTHROPIC_API_KEY=sk-ant-...       # включить LLM-judge
npm start                                   # → http://localhost:8090
```

Дашборд: балл-гейдж, таблица кейсов (pass/fail + детали), кнопки «прогон»,
«поведенческий», «сохранить baseline», индикатор регрессий.

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET`  | `/api/health` / `/api/cases` | статус и список кейсов |
| `POST` | `/api/run` | контрактный прогон против `target` → scorecard + сравнение |
| `POST` | `/api/run-behavior` | поведенческий прогон против витрины |
| `GET`  | `/api/scorecard` | последний прогон + регрессии |
| `POST` | `/api/baseline` | зафиксировать текущий прогон как baseline |
| `POST` | `/api/judge` | LLM-оценка ответа по рубрике (нужен ключ) |
| `POST` | `/api/ask` | сводка по прогону/регрессиям |

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `TARGET_URL` | `http://localhost:8080` | Цель контрактных эвалов |
| `CHAT_URL` | `http://localhost:8070` | Витрина для поведенческих эвалов |
| `EVAL_TIMEOUT_MS` | `5000` | Таймаут запроса |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | — / `claude-opus-4-8` | LLM-judge |
| `PORT` | `8090` | Порт |

## Тест

```bash
npm test
```

`test/smoke.mjs` проверяет: контрактный набор против **исправного** (балл 100) и
**сломанного** (нет `price`, неверный `total`, IDOR, принимает пустой заказ →
конкретные провалы) бэкендов, обнаружение **регрессий** против baseline, поведенческий
набор против mock-витрины, и HTTP-эндпоинты. Без сети и ключа. 17/17.
