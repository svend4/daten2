# Green / FinOps-роутер (Green Router)

Роутер, который выбирает уровень **не только по скорости**, а по **композитной
стоимости** из четырёх осей: латентность · деньги (€/запрос) · углерод (CO₂/запрос)
· надёжность — с настраиваемыми весами. Плюс **учёт FinOps**: сколько денег, энергии
и выбросов накоплено на каждом уровне. «Самооптимизация» становится про себестоимость
и экологию, а не только про миллисекунды.

```
запрос → composite = w_lat·лат + w_cost·€ + w_carbon·CO₂ + w_rel·(1−надёжн.)
         (нормировка по живым уровням) → argmin → уровень → замер → FinOps-учёт
```

## Многокритериальный выбор

Каждый уровень имеет профиль: `cost` (€/запрос), `watts` (мощность), `grid`
(углеродоёмкость сети, gCO₂/кВт·ч). Латентность и надёжность **изучаются онлайн**
(EWMA по реальным запросам). Модель энергии/углерода:

```
энергия(Дж) = base + watts × латентность(с)
CO₂(мг)     = энергия(кВт·ч) × grid(gCO₂/кВт·ч) × 1000
```

Композит нормирует метрики по живым уровням и взвешивает. **Веса задают политику** —
профили `⚡ Быстро`, `💶 Дёшево`, `🌱 Зелено`, `⚖ Баланс`. Смена весов **на лету
меняет выбор**: тот же набор уровней, но оптимум по скорости / цене / углероду —
разный.

## FinOps-учёт

На каждый обслуженный запрос накапливается: **стоимость (€)**, **энергия (Вт·ч)**,
**выбросы (г CO₂)** — суммарно и по уровням. Ответы несут заголовки
`X-Served-By-Level` и `X-CO2-mg`. При сбое уровня — **failover** на следующий по
композиту.

## Два движка объяснения

`POST /api/ask`: с `ANTHROPIC_API_KEY` — Claude-аналитик (данные из `router_state`,
советует как сместить веса ради скорости/экономии/экологии); без ключа —
детерминированные ответы (выбор, углеродный след, FinOps-итоги).

## Запуск

```bash
npm install
export ROUTER_BACKENDS='[{"id":"level1","name":"PHP","url":"http://localhost:8081","cost":0.0008,"watts":12,"grid":300}]'
# веса можно задать через W_LATENCY / W_COST / W_CARBON / W_RELIABILITY
npm start          # → http://localhost:8091
```

Дашборд: ползунки весов + профили, таблица уровней (композит/латентность/€/CO₂),
кнопка «20 запросов», накопленные FinOps-итоги.

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET`  | `/api/health` | `{ ok, engine, backends, weights }` |
| `GET`  | `/api/router/stats` | решение + FinOps |
| `GET`  | `/api/router/decide` | композит по уровням |
| `GET`  | `/api/router/finops` | накопленные €/энергия/CO₂ |
| `GET`/`POST` | `/api/weights` | веса критериев (профили) |
| `POST` | `/api/router/refresh` | health-опрос уровней |
| `ALL`  | `/api/products`, `/api/orders`, `/api/orders/:id` | проксирование (заголовки `X-Served-By-Level`, `X-CO2-mg`) |
| `POST` | `/api/ask` | объяснение выбора |

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `ROUTER_BACKENDS` | локальные L1/2/4/5/6 | Уровни + профиль (cost/watts/grid) |
| `W_LATENCY` / `W_COST` / `W_CARBON` / `W_RELIABILITY` | `0.4/0.3/0.2/0.1` | Веса критериев |
| `BASE_JOULES` / `EWMA_ALPHA` | `0.5` / `0.3` | Энергобаза и скорость обучения |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | — / `claude-opus-4-8` | LLM-советник |
| `PORT` | `8091` | Порт |

## Тест

```bash
npm test
```

`test/smoke.mjs` поднимает три уровня (быстрый / дешёвый / зелёный) и проверяет:
модель CO₂ (чистая сеть → меньше выбросов), что **веса смещают выбор** (скорость→A,
цена→B, экология→C), учёт FinOps (€/энергия/CO₂), заголовок `X-CO2-mg`, прокси и
`/api/ask`. Без сети и ключа. 13/13.
