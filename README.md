# Twin-in-loop governor 🛡️🔁🌷

Замкнутый контур **MPC-безопасности**: предложенное автономным управляющим действие сперва проигрывается на **цифровом двойнике**, и губернатор допускает его в прод только при **безопасном и выгодном** прогнозе. Небезопасное — блокирует и рекомендует безопасную альтернативу; спорное — эскалирует человеку.

> Часть системы [flower-shop / 7 уровней](https://github.com/svend4/daten2). Соединяет автономного управляющего (`:8077`, предлагает действия) и цифрового двойника (`:8075`, симулирует) предохранителем: ни одно действие не идёт в прод, не пройдя симуляцию.

## Чем отличается от соседей по системе

| Сервис | Роль |
|---|---|
| **Автономный управляющий** `:8077` | **предлагает** действия (дозаказ/цены) + своя эскалация |
| **Цифровой двойник** `:8075` | **симулирует** спрос/трафик |
| **Twin-governor** | **предохранитель**: гейтит каждое действие прогоном на двойнике перед проды |

## Как это работает

1. **Симулятор-двойник** (`sim.js`) — детерминированная модель магазина на горизонт: эластичный по цене спрос, порча товара каждый шаг (цветы!), учёт кэша и стока. Действие применяется в шаге 0, состояние катится вперёд → прогноз метрик (прибыль, выручка, порча, дефицит, минимальный кэш).
2. **Стражи** (`predicates.js`) — жёсткие (`insolvency` — кэш ушёл в минус; `excessive-waste` — порча выше порога) и мягкие (`understocked`; `not-beneficial` — прогноз не лучше бездействия).
3. **Губернатор** (`governor.js`) — симулирует действие **и** «ничего не делать» (базовая линия); решение:
   - жёсткое нарушение → **block**;
   - не лучше бездействия → **block**;
   - безопасно и выгодно, но есть мягкий риск → **escalate** (человеку/LLM);
   - безопасно и выгодно → **admit**.
   При блоке/эскалации перебирает альтернативы (меньшая закупка, мягче переоценка) и **рекомендует** безопасную выгодную.
4. **Два движка**: без ключа — детерминированные стражи. С `ANTHROPIC_API_KEY` — **LLM-арбитр** (`claude-opus-4-8`) для эскалированных (мягкий риск) действий.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET  | `/api/health` | движок + статистика решений |
| GET  | `/api/state` | текущее состояние магазина-двойника |
| POST | `/api/simulate` | `{action, steps?}` → сырой прогноз метрик (без решения) |
| POST | `/api/propose` | `{action, alternatives?, config?}` → решение губернатора (+ LLM-арбитр при эскалации) |
| GET  | `/api/log` | журнал решений |
| POST | `/api/reset` | сбросить состояние двойника |
| POST | `/api/ask` | объяснение словами (блоки, последнее решение) |

Действие: `{type:'reorder', productId, quantity}` или `{type:'reprice', productId, newPrice}`.

## Запуск

```bash
npm install
npm test                 # 17 проверок: допуск/блок/эскалация + рекомендация + инварианты + HTTP
node server.js           # :8110, дашборд на /
```

Дашборд (`/`): форма предложения действия, вердикт губернатора (admit/block/escalate) с прогнозом vs бездействие, нарушения, рекомендованная альтернатива, журнал решений.

## Переменные окружения

| Переменная | Смысл |
|---|---|
| `PORT` | порт (по умолчанию 8110) |
| `ANTHROPIC_API_KEY` | включает LLM-арбитра эскалаций |

Смоук-тест детерминирован: разумный дозаказ 25 роз ДОПУЩЕН (uplift > 0, платёжеспособность цела); безрассудный дозаказ 100 роз ЗАБЛОКИРОВАН по неплатёжеспособности, а губернатор рекомендует безопасную меньшую закупку (которая сама проходит гейт); удвоение цены тюльпана ЗАБЛОКИРОВАНО (спрос обвалился, выросла порча). Плюс: губернатор не мутирует исходное состояние магазина, повтор даёт тот же вердикт.
