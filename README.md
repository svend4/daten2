# Counterfactual AI-ops ledger 📒🌷

Append-only **хэш-цепь операционных решений ИИ** + **off-policy оценка**: сколько заработала бы *другая* политика на уже залогированных решениях — **без её выката**. Отвечает на вопрос «а что было бы, если бы роутер/дозаказ/цена выбирались иначе», не подвергая продакшн риску A/B-эксперимента.

> Часть системы [flower-shop / 7 уровней](https://github.com/svend4/daten2). Сервисы ИИ постоянно принимают решения: ML-роутер выбирает уровень, автономный управляющий — дозаказ, green-роутер — компромисс €/CO₂. Ledger превращает эти решения в актив: журнал, из которого честно оценивается ценность альтернативных политик.

## Чем отличается от соседей по системе

| Сервис | Подход |
|---|---|
| **shadow/canary** | выкатывает кандидат на **живой** трафик (нужен онлайн-эксперимент) |
| **авто-эвалы** | качество ответа против **rubric** |
| **событийная шина** | журнал доменных **событий** (заказы/просмотры) |
| **Ops-ledger** | журнал **решений** + **контрфактуальная** оценка политик **офлайн**, из уже собранных данных |

## Как это работает

1. **Append-only журнал (event sourcing)** — два вида событий: `decision` (что выбрали, какие были альтернативы с атрибутами, и `propensity` — вероятность выбора логирующей политикой) и `outcome` (наблюдённая награда **выбранного** действия). Награда не мутирует решение — это отдельное событие, поэтому **хэш-цепь остаётся целой**.
2. **Tamper-evident хэш-цепь** (`hashchain.js`) — каждое событие хэшируется вместе с хэшем предыдущего (SHA-256). Любая правка задним числом ломает цепь → журнал **доказуемо** append-only.
3. **Off-policy evaluation** (`ope.js`) — оценка ценности целевой политики π по логам:

   ```
   V(π) ≈ (1/n) Σ_i [ π(a_i | x_i) / p_i ] · r_i     (IPS, Horvitz–Thompson)
   ```

   Награды **невыбранных** действий не используются и **не выдумываются** — только перевзвешивание уже наблюдённого там, где π согласна с логом. **SNIPS** — самонормированный вариант (меньше дисперсия). **ESS** (эффективный размер выборки) и **overlap** честно сигналят, когда оценка ненадёжна (мало общего носителя политик).
4. **Regret** — насколько лучшая из рассмотренных политик превосходит логирующую. Это и есть «упущенная ценность» текущей автоматики.
5. **Два движка**: без ключа — детерминированная оценка. С `ANTHROPIC_API_KEY` — **LLM-советник** (`claude-opus-4-8`): переключать / собрать больше данных / оставить, с учётом надёжности оценки.

## Встроенные политики

`cheapest` · `fastest` · `greedy-reward` (по предсказанию) · `most-reliable` · `uniform` — как распределения π(action | context), поэтому работают и детерминированные, и стохастические.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET  | `/api/health` | движок, число решений/исходов, список политик |
| POST | `/api/decision` | `{domain, context, actions:[{id,cost,latency,predicted,…}], chosen, propensity, ts?}` → id |
| POST | `/api/resolve` | `{id, reward}` — наблюдённый исход выбранного действия |
| GET  | `/api/ledger` | журнал (последние 200) + целостность цепи |
| GET  | `/api/verify-chain` | проверка tamper-evident цепи |
| POST | `/api/evaluate` | `{policies?, domain?}` → SNIPS/IPS/ESS по политикам + regret + рекомендация |
| POST | `/api/ask` | `{message}` → объяснение словами (политики, regret, целостность) |

## Запуск

```bash
npm install
npm test                 # 16 проверок: off-policy оценщик на среде со скрытой истиной + tamper + HTTP
node server.js           # :8104, дашборд на /
```

Дашборд (`/`): бар-чарт off-policy ценности каждой политики против пунктира текущей, таблица SNIPS/IPS/ESS/overlap с флагом надёжности, regret, кнопка проверки цепи.

## Переменные окружения

| Переменная | Смысл |
|---|---|
| `PORT` | порт (по умолчанию 8104) |
| `ANTHROPIC_API_KEY` | включает LLM-советник по смене политики |

Смоук-тест строит среду со **скрытыми** истинными наградами: логирующая политика ε-жадная по *мискалиброванному* `predicted` (гонится за посредственным армом), а по факту лучший арм — самый быстрый. Оценщик из **одного** журнала честно восстанавливает: равномерная политика ≈ средняя истинная награда, «fastest» превосходит логирующую (положительный regret), хотя её никогда не выкатывали — и хэш-цепь ловит подмену события.
