# Дистилляция «учитель → ученик» (Distillation)

Наши **детерминированные движки — готовые разметчики**. Этот сервис берёт правило-
классификатор намерений покупателя как **учителя**, генерирует размеченный им датасет,
и обучает крошечную **softmax-модель с нуля** (без зависимостей) — **ученика**, который
повторяет учителя, но работает как дешёвый **офлайн-инференс** без правил и без API.

```
учитель (правила) ──размечает──▶ датасет ──обучение (GD)──▶ ученик (softmax-веса)
                                                              └─ дешёвый инференс, экспорт весов
                                          согласие ученика с учителем ≈ 92%
```

## Пайплайн

- **Учитель** (`teacher.js`) — правила классификации намерения в 7 классов
  (`greet · catalog · add · filter · checkout · cart · unknown`). Опционально —
  Claude как учитель (лучшая разметка) при `ANTHROPIC_API_KEY`.
- **Датасет** (`dataset.js`) — сбалансированная генерация RU-фраз по классам
  (шаблоны + слоты), метку ставит учитель; воспроизводимо по seed.
- **Признаки** (`features.js`) — хэш-фичи (униграммы + биграммы), фиксированная размерность.
- **Ученик** (`student.js`) — мультиклассовая **softmax-регрессия**, обучение
  полнобатчевым градиентным спуском с **балансировкой классов** и L2. Нулевая
  инициализация → **детерминированно** (один seed → та же модель). Инференс:
  `b + W·x` по активным признакам — микросекунды, без сети.
- **Оценка** (`distill.js`) — train/test split, метрика = **согласие ученика с
  учителем** на held-out.

Ученик достигает **≈92% согласия** с учителем и **экспортируется** компактными
весами (нули обрезаны) — готов к встраиванию в любой уровень/клиент для локального
инференса.

## Два учителя, один ученик

Без ключа учитель — детерминированные правила. С `ANTHROPIC_API_KEY` учителем может
быть **Claude** (`claude-opus-4-8`): он размечает данные точнее, а дистилляция
переносит это знание в дешёвую локальную модель. Ученик в обоих случаях локальный.

## Запуск

```bash
npm install
npm start          # → http://localhost:8089 (модель обучается при старте, ~сек)
# export ANTHROPIC_API_KEY=sk-ant-...   # учитель = Claude
```

Дашборд: метрики модели (согласие/loss/размер датасета), кнопка «Переобучить»,
экспорт весов, и проверка любой фразы — **ученик vs учитель** бок о бок.

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET`  | `/api/health` / `/api/metrics` | статус + метрики (согласие, loss) |
| `POST` | `/api/train` | `{ n, seed, epochs, lr }` → переобучить, вернуть метрики |
| `POST` | `/api/classify` | `{ text }` → предсказание ученика + метка учителя + совпадение |
| `POST` | `/api/teacher` | `{ text }` → эталонная метка учителя |
| `GET`  | `/api/model` | экспорт компактной модели (переносимые веса) |

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `FEATURE_DIM` | `1024` | Размерность хэш-признаков |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | — / `claude-opus-4-8` | Учитель = Claude |
| `PORT` | `8089` | Порт |

## Тест

```bash
npm test
```

`test/smoke.mjs` проверяет: генерацию размеченных данных, **согласие ученика с
учителем ≥ 0.9**, детерминизм (один seed → идентичная модель), корректный инференс
на явных примерах, экспорт/импорт весов (round-trip), и HTTP. Без сети и ключа. 15/15.
