# Уровень 4 — Node.js + Express + EJS + SQLite

Серверный рендеринг на JavaScript: Express отдаёт HTML, собранный из EJS-шаблонов,
данные читаются и пишутся напрямую в SQLite.

Структура (как в чате 14.12.2025):

```
flower_shop/
├── server.js              # Запуск сервера (порт, логи, сигналы)
├── app.js                 # Настройка Express: шаблоны, статика, маршруты
├── package.json           # Зависимости npm
├── flowers.db             # База данных (SQLite, уже заполнена)
├── views/                 # EJS шаблоны
│   ├── index.ejs          # Каталог
│   ├── product.ejs        # Карточка товара
│   ├── order.ejs          # Заказ принят
│   └── 404.ejs            # Страница не найдена
└── public/
    └── style.css
```

## Маршруты

| Маршрут            | Что делает                                                    |
|--------------------|---------------------------------------------------------------|
| `GET /`            | Каталог товаров из таблицы `products`                         |
| `GET /product/:id` | Карточка одного товара                                        |
| `POST /order`      | Записывает заказ в `orders` + `order_items`, показывает номер  |
| остальное          | 404                                                           |

## Запуск

```bash
npm install
npm start
```

Открыть: http://localhost:3000

Порт задаётся переменной окружения `PORT` (её читает `server.js` через `dotenv`):

```bash
PORT=3004 npm start
```

Открыть: http://localhost:3004
